# TFG - Pronóstico de Matriculaciones de Turismos y Vehículos Eléctricos

Repositorio con los scripts en R desarrollados para el Trabajo de Fin de Grado:
**"Pronóstico de Matriculaciones de Turismos y Vehículos Eléctricos con TBATS y LSTM"**.

## Estructura

### Scripts principales
- `01_diagnostico_regresion.R` — Diagnóstico y modelos de regresión.
- `02_clustering_municipios.R` — Clustering de municipios.
- `03_prophet_comparacion.R` — Comparación con el modelo Prophet.
- `Análisis matriculaciones.R` — Análisis exploratorio de matriculaciones.
- `MD diario.R` — Procesamiento de datos diarios.
- `MD_red_neuronal.R` — Modelo de red neuronal (LSTM).
- `MD_red_neuronal_historico.R` — Red neuronal sobre histórico.

### Pipeline (`pipeline/`)
- `update_pipeline.R` — Actualización del flujo de datos.
- `export_md_diario.R` — Exportación de datos diarios.
- `export_prophet.R` — Exportación de resultados de Prophet.
